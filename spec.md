# Product Spec: Penguin Focus (Web MVP)

## Vision
A gamified Pomodoro timer where a penguin character travels across the Arctic. The goal is "Time to Delight" through smooth animations and a cozy "Arctic Vibe."

## Core Features (Sprint 1)
- **Timer Engine**: 25m focus / 5m break.
- **Visual Journey**: A Penguin sprite/icon that moves along a progress bar or "map" upon session completion.
- **Persistence**: Save trip progress to `localStorage`.
- **Sound**: Notification chime on completion.

## Aesthetic "Vibe"
- **Colors**: Soft Arctic blues, frosted glass (Glassmorphism), and whites.
- **Feel**: Calm, minimalist, and rewarding.

## Tech Stack
- Next.js / Tailwind CSS / Lucide-React
